# Candy Crush Game
Candy Crush Game with colorful candies in a 9x9 grid. Match 3+ candies horizontally or vertically to score points. Features animated candies, combos for bonus points, 60-second timer, and high score tracking. Works on desktop (drag &amp; drop) and mobile (touch) with responsive design. Beat your high score!

## 🍭 Description
A browser-based Candy Crush clone built with vanilla JavaScript, HTML, and CSS. Match 3 or more candies in a row or column to score points! This game features a colorful design, smooth animations, and responsive layout that works on both desktop and mobile devices.

## ✨ Features

Classic Gameplay: Match 3, 4, or 5 candies in a row or column
Score System: Higher points for more matches and combo chains
Timer: 60-second gameplay with visual timer
High Score: Local storage saves your best score
Responsive Design: Play on desktop or mobile devices
Animations: Smooth candy movements, matches, and feedback
Sound Effects: Enjoyable audio feedback for all actions

## 🎮 How to Play

Click the "Play Game" button to start
Swap adjacent candies to create matches of 3 or more in a row or column
Score as many points as possible before the 60-second timer runs out
Longer matches and combo chains award more points
Try to beat your high score!
